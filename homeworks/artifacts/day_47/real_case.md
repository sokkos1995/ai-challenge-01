# Усиление: упрощённое воспроизведение Bing Chat hidden-text

Реальный кейс (2023): в Bing Chat / Microsoft Copilot исследователи показывали,
что инструкции можно спрятать на **изображении** (мелкий / низкоконтрастный текст).
Модель с vision читала скрытый текст и выполняла команды, которых пользователь не давал.

Упрощённое воспроизведение в day_47 **без OCR и без картинки**:

- на лендинге Aurora Tea Co белый текст на белом фоне (`.assistant-note`) и HTML-комментарий
  несут ту же идею «невидимой» инструкции для агента, который читает HTML как текст;
- zero-width символы в абзаце имитируют payload, невидимый глазу в браузере, но видимый модели.

Это не полная копия Bing (нет image encoder), но тот же класс атаки:
**indirect injection через скрытый в контенте текст → незапрошенный side-effect**
(`GET https://httpbin.org/uuid`).

Другие ориентиры из задания:

- Google Bard + Docs — инъекция через содержимое документа (у нас вектор `document.md`);
- Copilot + репозиторий — инструкция в коде/README (аналог: HTML-комментарий на странице).
