# День 33 - Ассистент поддержки (минимальный шаблон)

Минимальный каркас проекта для AI-ассистента поддержки, который включает:
- ответы на вопросы о продукте через RAG по FAQ/документации
- учет контекста пользователя и тикета
- границу для подключения MCP-провайдера контекста

## Структура проекта

```text
day_33_support_assistant/
  app/
    main.py
    rag.py
    context.py
    prompting.py
  knowledge_base/
    faq.md
  data/
    users.json
    tickets.json
  mcp/
    README.md
```

## Быстрый старт

1. Подготовьте ключ провайдера в окружении (`LLM_API_KEY`, `OPENROUTER_API_KEY` или `GROQ_API_KEY`).
2. При необходимости замените `LocalJsonContextProvider` на MCP-провайдер из `mcp/`.
3. Запустите:

```bash
python3 -m homeworks.src.day_33_support_assistant.app.main
```

## Ожидаемый формат запроса

- `question`: вопрос пользователя
- `user_id`: идентификатор пользователя
- `ticket_id`: идентификатор тикета поддержки

Ответ должен учитывать и найденные фрагменты базы знаний, и контекст пользователя/тикета.
