# 🔥 День 35. Реальная задача — AI task tracker (Todoist-like)

## Какую задачу решал

Сделал мини-сервис таск-трекера, который автоматизирует разбор большой цели на исполнимые задачи и подзадачи.

Реальный кейс: вместо ручного планирования по релизу/инфре/рабочему процессу пользователь пишет цель, а сервис формирует backlog.

## Где код

- `homeworks/todoist/main.py` — CLI и демо-сценарий
- `homeworks/todoist/service.py` — бизнес-логика task tracker
- `homeworks/todoist/ai.py` — AI-декомпозиция цели (LLM + fallback)
- `homeworks/todoist/storage.py` — JSON-хранилище
- `homeworks/todoist/models.py` — модель задачи
- `homeworks/todoist/README.md` — инструкция по запуску

## Как AI участвует

Команда `ai_plan`:

1. Принимает реальную цель пользователя (например, "подготовить релиз приложения").
2. Отправляет цель в LLM.
3. Получает структурированный JSON-план:
   - заголовок задачи,
   - приоритет,
   - срок,
   - теги,
   - список подзадач.
4. Сохраняет родительскую задачу и подзадачи в task tracker.

Если API-ключ не задан, включается fallback-режим, чтобы сервис продолжал работать в локальном окружении.

## Почему это "реальная задача"

- Работает с постоянным хранилищем (`tasks.json`), а не с разовым print в консоль.
- Подходит для повседневной работы: планирование релиза, инфраструктурных задач и рутины.
- Можно использовать с реальной LLM (через ключ провайдера).

## Как запустить

```bash
python3 -m homeworks.todoist.main demo
```

Полезные команды:

```bash
python3 -m homeworks.todoist.main add "Собрать метрики релиза" --priority high
python3 -m homeworks.todoist.main ai_plan "Подготовить релиз мобильного приложения"
python3 -m homeworks.todoist.main list
```

Для реального AI укажите один из ключей:

- `LLM_API_KEY`
- `OPENROUTER_API_KEY`
- `GROQ_API_KEY`
