🔥 День 31. Ассистент разработчика

## Цель

Собрать минимального ассистента разработчика, который:

- понимает структуру проекта через RAG-контекст (`README` + `docs`);
- умеет получать git-контекст через MCP (минимум текущая ветка);
- поддерживает команду `/help` в chat-режиме.

## Что реализовано

### 1) Документация для RAG

Подключены источники проектного контекста:

- `README.md` (основная документация проекта);
- `docs/dev-assistant.md` (добавлен файл с краткой структурой и назначением `/help`).

Итог: минимальное требование `README + docs` выполнено.

### 2) MCP для git-контекста

Добавлен локальный MCP-сервер:

- файл: `app/mcp_servers/git_server.py`;
- транспорт: `stdio`;
- инструменты:
  - `get_current_branch(repo_path=".")` — возвращает текущую git-ветку;
  - `get_short_status(repo_path=".")` — возвращает краткий `git status --short`.

Пример запуска:

```bash
python3 -m app.mcp_servers.git_server
```

Итог: минимальное требование по MCP (`git branch`) выполнено.

### 3) Команда `/help` в ассистенте

Добавлена обработка help-команды в chat loop:

- `app/services/chat_command_service.py`:
  - новый handler `handle_help_command(...)`;
  - текстовая справка по доступным командам.
- `app/cli.py`:
  - подключен вызов `handle_help_command` до генерации ответа LLM.

Команда:

- `/help` (также поддержаны `help` и `@help`) — выводит список доступных команд и режимов.

## Измененные файлы

- `app/cli.py`
- `app/services/chat_command_service.py`
- `app/mcp_servers/git_server.py`
- `docs/dev-assistant.md`
- `README.md`

## Проверка

1. Запуск chat-режима:

```bash
python3 llm_cli.py --chat --rag
```

2. Проверка `/help`:

- в чате отправить `/help`;
- ожидание: агент печатает список поддерживаемых команд.

3. Проверка MCP git:

```bash
python3 -m app.mcp_servers.git_server
```

- ожидание: сервер запускается без ошибок и предоставляет инструменты `get_current_branch`, `get_short_status`.

## Результат

Собран минимальный ассистент разработчика для проекта:

- использует документацию проекта (`README` + `docs`) как базу контекста для RAG;
- получает git-контекст через MCP-инструменты;
- поддерживает `/help` для навигации по возможностям в chat-режиме.
