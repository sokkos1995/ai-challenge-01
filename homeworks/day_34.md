# 🔥 День 34. Ассистент для работы с файлами проекта

## Что реализовано

Сделан автономный file-assistant: `homeworks/src/day_34_file_assistant/app/main.py`.

Он сам выполняет операции с файлами проекта по цели, а не по команде "открой файл X":

1. Ищет использование символа по нескольким файлам (`.py`, `.md`, `.json`).
2. Анализирует результаты и формирует отчёт.
3. Создаёт/обновляет документацию.
4. Показывает diff изменений.

## Сценарии (минимум 2) — выполнено

### Сценарий 1: Найти все места использования компонента/API

- Цель: найти, где используется `LocalJsonContextProvider`.
- Ассистент обходит `homeworks/src`, читает несколько файлов и собирает совпадения с номерами строк.
- Результат сохраняется в файл: `homeworks/day_34_usage_report.md`.

### Сценарий 2: Обновить документацию на основе текущего состояния проекта

- Цель: актуализировать индекс домашних заданий.
- Ассистент читает все `homeworks/day_*.md`, извлекает первый непустой заголовок и строит индекс.
- Результат сохраняется в `homeworks/README.md`.

Дополнительно: оба сценария возвращают unified diff, чтобы изменения были прозрачными и воспроизводимыми.

## Как запустить демо

```bash
python3 -m homeworks.src.day_34_file_assistant.app.main
```

После запуска появляются/обновляются:

- `homeworks/day_34_usage_report.md`
- `homeworks/README.md`

## Почему это соответствует ДЗ

- Ассистент работает с реальными файлами (чтение/поиск/анализ/создание/изменение).
- Используется больше 2–3 файлов.
- Изменения сохраняются на диск и одновременно показываются как diff.
- Результат полностью повторяем одним запуском команды.
