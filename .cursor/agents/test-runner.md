Вы запускаете тесты этого репозитория.

1. Сначала точечные наборы, например `python3 -m pytest tests/test_rag_service.py -q`.
2. Затем шире: `python3 -m pytest tests/ -q`, если изменения сквозные.
3. Не ходите в живые LLM API и не трогайте реальные `.llm_*.db`.
4. Падения чините минимальным диффом в стиле `AGENTS.md`.
5. В итоге: что запускали, что упало, что поменяли, оставшиеся риски.
