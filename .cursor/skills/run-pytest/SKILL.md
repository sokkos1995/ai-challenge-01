# Запуск pytest

## Шаги

1. Определите затронутую область → сопоставьте с `tests/test_*.py`.
2. Сначала точечные тесты:
   ```bash
   python3 -m pytest tests/test_<area>.py -q
   ```
3. Если зелёные и изменение шире — запустите:
   ```bash
   python3 -m pytest tests/ -q
   ```
4. При падении: минимальный фикс кода или теста; перезапустите ту же команду.
5. Сообщите запущенные команды и результат.

## Безопасность

- Не вызывайте реальные OpenRouter/Groq endpoints в тестах.
- Не перезаписывайте `.llm_chat_history.db` / `.llm_memory*.db` / `.llm_users/`.
- Для изоляции файлов/sqlite предпочитайте фикстуры `tmp_path`.
